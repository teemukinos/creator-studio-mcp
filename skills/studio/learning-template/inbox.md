# Inbox: lessons waiting for curation

Sessions append here at the end of each unit (SKILL.md, A8). Curation moves an entry into a reference file, a recipe, a tool change or SKILL.md, or drops it. Sessions never delete entries.

One line per lesson, at most five per unit, only lessons that would help a different job. No job content: no song, client or file names, no lyrics, no copy.

Format: `- YYYY-MM-DD | <job type>/<tool> | <dead-end, recipe, cost, intake or guard> | <the lesson in one sentence> | evidence: <numbers from measure_session or the log>`

Kinds: dead-end (a route that failed twice), recipe (a route that now works as one call), cost (a stage that cost far more than it should, and why), intake (a question that should have been asked up front), guard (a failure a tool should refuse instead of a rule).
